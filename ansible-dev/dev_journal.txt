## [2026-05-23] The LVM "Symmetry" and "Absorber" Pivot
**Incident**: Discovered that L1 reported success despite packages missing because `pstat_base_packages` was accidentally deleted from `group_vars`. 
**Resolution**: Restored a "Golden Copy" of network identities and base tool lists. Verified that "Absolute Zero" boot requires a strict L1 $\rightarrow$ L2 sequence.
**Architectural Shift**: Moved from a "Workhorse" volume to an "Alta-inspired" `/local` absorber volume (70GB). This isolates all user-driven disk pressure (home dirs, containers, downloads) from the OS root partition.
**LVM Lesson**: `vgremove` and `pvremove` can fail if `auditd` or other system services hold files open. The most efficient recovery path for LVM iterative testing is a Harvester "Replace Existing" snapshot restore.
**Provisioning State**: `forger16` and `forger17` now have symmetrical L1/L2 baselines and L3 `/local` storage.

## [2026-05-26] L3 Fortress Completion and Stabilization
**Achievement**: Successfully implemented the full Layer 3 (LVM + Quotas) pipeline.
**Key Technical Fixes**:
- Standardized on `/dev/mapper/` device paths in `fstab` to ensure mount reliability.
- Implemented `nofail` mount options and a `systemd` override for `auditd.service` (`RequiresMountsFor=/var/log/audit`) to eliminate Emergency Mode boot-loops.
- Enabled XFS User, Group, and Project quota accounting on `/local` and `/tmp`.
**Final State**: `forger19` and `forger20` are now fully built to the L3 baseline. Both nodes have been powered down and snapshotted at this state, providing a stable, verified recovery point before moving to Layer 4.
