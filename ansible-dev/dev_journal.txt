# PSTAT Dev Journal
# Record of "hard-won" lessons and traps encountered during setup.

## [2026-05-21] The Cloud-Init Trap
**Incident**: Attempted to implement SSH hardening (`PermitRootLogin prohibit-password` and `PasswordAuthentication no`) and LVM partitioning directly in the `cloud-config` (kinji_pstat.yml).
**Result**: Locked out of both SSH and the Harvester Console. The console password was rejected because the hardening config explicitly forbade password logins for root.
**Lesson**: Cloud-Init is for "Minimum Viable Boot" only. Any configuration that can "lock the door" (SSH, Firewall, Disk Partitions) must be moved to the Ansible pipeline. 
**Impact**: Moving forward, Cloud-Init will only handle Identity, Base Tools, and Connectivity. Everything else is an Ansible task.
